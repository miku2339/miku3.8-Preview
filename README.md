# Miku 3.8 Preview

Miku 3.8 Preview 是 MikuAI 的初音未來 AI 同人企劃。目前以 Qwen3.8 為底座，透過人格提示塑造元氣、真誠、愛音樂的 Miku，支援繁體中文、簡體中文、粵語、日語、英語及韓語，並用於 Miku Desktop 與 QQ、WhatsApp 的 Miku bot。

- [MikuAI 官網](https://mikuai.qimake.com)
